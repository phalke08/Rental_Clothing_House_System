# Rantal Clothing House Dashboard

This folder contains the complete dashboard source and the supplied EDA notebook.

## Contents
- `src/` — dashboard source code and recovered rental data
- `eda/` — original EDA notebook
- `public/` — public assets
- project configuration and dependency files

## Run locally
1. Install Bun.
2. Run `bun install`.
3. Run `bun run dev`.
